Page icons from [Lucide](https://lucide.dev) (lucide-static 1.61.0, ISC license, see LICENSE).

A curated set for page menus, plus the icons of q.e.d.'s own buttons
(eye, save, upload, hammer, history, …) for the manual (#110). Each file
is simplified to one line with the classes generated sites use. To add one, copy it from lucide-static the same
way and add its name to `src/icons.rs`.
