## Was Sie brauchen

:::: columns
::: column
title = "Einen Computer"
boxed = true
:::

:icon-house: Mit macOS (Apple Silicon oder Intel), Windows oder Linux
(Ubuntu 22.04 oder neuer, oder eine gleich alte Distribution). Dort
läuft q.e.d., und dort liegt auch Ihre Website: ihre Seiten, Bilder und
ihre Geschichte.

::: column
title = "Webspace"
boxed = true
:::

:icon-globe: Platz auf einem Webserver, den Sie über **SFTP** erreichen,
wie ihn fast jedes Hosting-Paket bietet: ein Servername, ein
Benutzername und ein Passwort oder Schlüssel
([Veröffentlichen](publishing.md)). Mehr braucht eine Website aus q.e.d.
nicht.

::: column
title = "Eine Domain"
boxed = true
:::

:icon-link: Eine Adresse wie `example.com`, meist vom selben Anbieter
wie der Webspace. Sie kommt in die **Web address** in den
[Einstellungen der Seite](site-settings.md).
::::

Für einen **Podcast** braucht der Webspace Platz für das Audio: Eine
Stunde MP3 sind etwa 50 bis 80 MB pro Episode und Format. Oder das Audio
bleibt bei einem Podcast-Hoster ([Podcasts](podcasts.md)).

Für **Sicherungen** auf einem anderen Computer, und um an einer Website
von zwei Computern aus zu arbeiten, hilft ein Git-Server wie Codeberg
oder GitHub ([Sicherungen](backups.md)). Er ist freiwillig.

## Was Sie nicht brauchen

- **Nichts auf dem Server** außer Dateien: kein PHP, keine Datenbank,
  kein WordPress, keine Updates, die dort zu installieren wären. Eine
  Website, die nur aus Dateien besteht, kann nicht über ihre Software
  geknackt werden, und sie ist schnell.
- **Kein Programmieren** und keine Kommandozeile: Alles entsteht in der
  App.
- **Kein Konto** bei q.e.d. und kein Abo. Die App ist kostenlos und
  funktioniert offline; nur das Veröffentlichen braucht das Internet.
- **Keine anderen Dienste** für Schriften, Player, Suche oder Statistik:
  Ihre Website bringt alles mit und schickt die Daten Ihrer Besucher an
  niemanden.
